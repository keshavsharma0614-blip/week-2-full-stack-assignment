# Week 2 - Backend Development

Backend development assignments using Node.js, Express.js and MongoDB.

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Postman

## Assignments

### 1. To-Do List REST API

- Create endpoints for adding, updating and deleting tasks
- Use MongoDB for data storage
- Test API using Postman

### 2. User Authentication API

- User registration
- User login
- Password encryption
- JWT-based authentication

### 3. Mini Project - Notes App Backend

- Develop a backend API for a notes-taking app
- Implement CRUD operations for notes
- Secure routes with JWT authentication
